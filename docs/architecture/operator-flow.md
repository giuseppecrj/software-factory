# Operator Flow

## First-time flow

1. Install the CLI globally.
2. Run `sf init` in the target repo.
3. Run `sf doctor`.
4. Confirm readiness.

## Day-to-day flow

1. `sf shape`
2. `sf plan`
3. `sf prototype --variants 3`
4. inspect candidate outputs
5. `sf review`
6. `sf qa`
7. choose winner
8. `sf retro`

## Principle

The operator should never need tribal knowledge to know what to run next.
